{% if language == "tr" %} Ollama Host nedir?

Ollama servisinin çalıştığı adresi belirtir. Ollama bu bilgisayara normal şekilde kurulduysa varsayılan http://localhost:11434 adresini değiştirmeniz gerekmez.

Ollama başka bir bilgisayarda çalışıyorsa o bilgisayarın IP adresini kullanabilirsiniz. Windows üzerinde Komut İstemi'nde ipconfig çalıştırıp IPv4 Address değerine bakabilirsiniz.

Örnek: http://192.168.1.50:11434

{% else %} What is Ollama Host?

This specifies the address where the Ollama service is running. If Ollama is installed normally on this computer, keep the default http://localhost:11434 address.

If Ollama runs on another computer, use that computer's IP address. On Windows, run ipconfig in Command Prompt and find the IPv4 Address value.

Example: http://192.168.1.50:11434

{% endif %}
{% if settings.help.show_info_buttons %} {% endif %}
{% if language == "tr" %} Model nasıl değiştirilir?

Önce Ollama'yı bilgisayarınıza kurun ve kullanmak istediğiniz modeli Ollama üzerinden indirin.

Daha sonra modelin tam adını bu alana yazın. Örnek: qwen2.5:7b

Agent araç kullandığı için tool/function calling desteği iyi olan modeller önerilir.

{% else %} How do I change the model?

Install Ollama first and download the model you want to use through Ollama.

Then enter the exact model name here. Example: qwen2.5:7b

Models with reliable tool/function calling support are recommended because the Agent uses tools.

{% endif %}

Saved credentials are not deleted when Telegram is disabled.

{% if language == "tr" %} Custom Local Access nedir?

Bu özellik yalnızca bu bilgisayardaki Local Admin Console ve yerel sesli komutlar için ek klasör erişimi sağlar.

Web Admin ve Telegram bu klasör izinlerini kullanamaz. Bu ayrım backend güvenlik katmanında uygulanır.

Final masaüstü EXE sürümünde Browse Folder düğmesi Windows klasör seçicisini açacaktır. Geliştirme sürümünde klasör yolunu manuel olarak ekleyebilirsiniz.

Custom erişim seçtiğiniz klasörlerde Agent'ın dosya okumasına ve izin verilen dosya işlemlerini gerçekleştirmesine olanak tanır.

AI Agent ayarları, secrets dosyaları, proje güvenlik dosyaları ve kritik Windows sistem alanları Custom Access ile açılmaz.

Dosya silme, taşıma, yeniden adlandırma ve yazma gibi işlemlerde mevcut kullanıcı onay sistemi devam eder.

{% else %} What is Custom Local Access?

This feature grants additional folder access only to the Local Admin Console and local voice commands on this computer.

Web Admin and Telegram cannot use these folder permissions. This separation is enforced by the backend security layer.

In the final desktop EXE, Browse Folder will open the native Windows folder picker. During development, paths can be added manually.

Custom access allows the Agent to read and perform permitted file operations inside folders you authorize.

AI Agent settings, secret files, security files and critical Windows system locations remain protected.

Existing confirmation checks remain active for delete, move, rename and write operations.

{% endif %}

{% if language == "tr" %} Dikkat

Custom Local Access, AI Agent'ın seçtiğiniz klasörlerde dosya oluşturmasına, değiştirmesine, taşımasına veya silmesine izin verebilir. Yanlış veya yanlış anlaşılan bir komut veri kaybına ya da bazı uygulamaların çalışmamasına neden olabilir.

Bu erişim yalnızca Local Admin Console ve yerel sesli komutlar içindir. Web ve Telegram bu ek izinleri kullanamaz.

{% else %} Warning

Custom Local Access may allow AI Agent to create, modify, move or delete files inside folders you authorize. An incorrect or misunderstood command may cause data loss or prevent applications from working correctly.

This access is only available to the Local Admin Console and local voice commands. Web and Telegram cannot use these additional permissions.

{% endif %}
